SolidWorks AI Assistant 5.1.1 — 安装构建说明

当前交付为源码版本，未生成或验收 5.1 安装程序。
开发运行请使用项目根目录 run.bat，首次环境安装见 README.md。

安装脚本已预留独立产品目录、开始菜单和卸载项，不覆盖 4.x。
用户数据默认存放在 %LOCALAPPDATA%\SolidWorksAIAssistantV5。
首次启动只读复制旧版本的模型配置、模型库和历史，之后各版本独立保存。
卸载保留用户数据。

默认不重新注册或注销共享的 C# 事件桥，避免破坏已安装旧版本。
无事件桥时 Python COM 工作进程仍可使用。共享桥升级应单独验收。
Pi 当前使用本机已安装的运行时；自动后端在不可用时回退内置持续会话。
完整 Pi 运行时随安装包分发仍须单独完成依赖和隔离安装验证。
