# SolidWorks 智能建模助手 V5

版本 `5.3.2`，源码位于 `SolidWorks-Assistant`。本项目来自 V4.2
`<workspace>/solidworks_tools_agent` 的独立副本，旧版本仍保留，便于比较和回退。

V5 将智能建模改为持续任务：记录目标和假设，读取实际模型状态，决定并执行一个阶段，再根据检查
结果决定下一阶段。成功结果和失败结果都参与后续决策；遇到需要人工检查的情况，保留任务并显示
操作建议，提交反馈、重新检查状态后可以继续。任务记录可恢复，恢复不会自动开始建模。

5.3.2 进行稳定性收敛：宿主按协议、方案、观察、环境、执行器契约和安全状态分别管理有限恢复；
候选失败不清空累计次数，人工核对后的额外窗口也受独立现场验证和全任务上限约束。
增加三种基准面 × 四类真实 CAD 操作验收及 10 任务 × 3 会话自主评分器。
清单存在不等于实测通过，实际覆盖与未完成项见
[5.3.2 稳定性收敛记录](docs/V532_STABILITY_CONVERGENCE.md)。原版保留为 `v5.3.1-baseline`（`3ee9498`）。

5.3.1 修复非前视草图的直线/中心线/矩形/圆坐标转换，并独立读回实际几何；失败前后的几何摘要
会保留到 Agent 上下文、诊断与原生阶段回执。Pi 整理上下文使用独立固定期限，不再误报普通
无响应并自动降级；进入人工检查后不会继续显示“将自动调整”。详见
[5.3.1 故障证据、修复与验证](docs/V531_COORDINATES_AND_FEEDBACK.md)。上轮源码保留于 `b3847b8`。

## 启动

```powershell
cd SolidWorks-Assistant
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[dev]"
.\run.bat
```

已有独立虚拟环境时直接运行 `run.bat`。首次使用在“设置 → 模型服务”核对接口地址、模型和
API Key。默认用户数据目录为 `%LOCALAPPDATA%\SolidWorksAIAssistantV5`；首次启动可从旧版本
读取并复制已有模型配置、模型库和历史，之后独立保存。Windows DPAPI 密钥仍绑定当前 Windows
用户，迁移到其他电脑时需要重新输入。

## 持续任务怎么用

1. 在默认“智能建模”页输入目标，点击“发送并开始”，Agent 自动准备并持续推进任务。
2. 在任务对话查看公开进度、调查与结果，在“需求与证据”检查原始要求、子目标和未完成验收。
3. 运行中可以继续输入补充要求，在下一安全边界生效；已完成步骤保留，未执行候选重新规划。
4. 普通可恢复错误先自主调查和调整；必要时才显示人工检查。进展不展示原始隐藏推理。
5. 人工反馈提交后先重新观察现场，通过验证才继续；纠正预算耗尽时，全任务最多另开一次有限窗口，
   执行器契约故障不能靠备注解禁，全局预算不重置。如包含新的尺寸或结构要求，勾选相应选项，
   让补充内容进入需求合同。与已锁定精确尺寸冲突时，目前需另开新任务；目标版本修订入口尚未提供。
6. “停止所有”调用应用统一停止入口，涵盖连续任务、固定计划、模型库读取和批处理。已被
   SolidWorks 受理的同步调用可能需要等待返回，停止并不代表自动撤销已完成操作。
7. “高级操作”保留仅准备、单阶段和近期任务恢复；恢复记录不会自动写模型。要换一个独立目标，
   点击“新任务”，原任务记录保留。
8. 已有成功检查点时，在高级操作点击“检查点列表”，选择版本后“恢复检查点副本”。新副本的
   几何和成功前缀通过校验后停在就绪；再点击“继续执行”才继续。若重启后仍有未知活动文档，
   先由你保存并处理该现场，程序不会擅自关闭它或接管旧候选。

“建模 → 兼容固定计划”仍可打开 V4.2 的固定计划页面。原来的本地模型库、参数读取与派生、
自动化中心、历史诊断和菜单功能继续保留。两个建模入口共享同一执行边界，不应同时运行。

## Agent 与 SolidWorks 的分工

Agent 负责阶段决策和依据结果调整方案；本地执行器负责工具参数检查、串行 COM 调用、前后快照
和后置条件验证。只有已实现并获准使用的工具才能执行。Pi 是可选推理运行时，不能自行获得
Shell、任意文件写入、动态代码、DLL 或直接 COM 权限。

保留的 V4.2 兼容路径使用 PydanticAI 做初始需求规划，使用 Pi 或后备监督器处理失败。
V5 持续任务的运行状态和通过条件以当前代码、任务记录和本轮验证结果为准；不能把旧版本的
245 项测试或旧安装包当作 V5 已验收的证据。

## 当前边界

- 工具覆盖之外的任意几何、复杂自由曲面及任意装配建模仍待扩展与验收。
- 多轮尝试不保证所有任务成功；模型状态未知时需重新观察或人工核对。
- 完全自动回滚任意 CAD 操作尚未验收，不能承诺每个失败都恢复原状。
- 工作进程重启后不会接管遗留活动文档或候选；可以在安全空现场显式打开已验证的持久检查点副本。活动草图和旧端面缓存不能直接恢复。
- 严格观察仍有性能成本：5.1 的隔离 Pi/CAD 棱柱闭环实测约 144 秒，复杂模型性能仍需优化。
- 正式 Pi 运行时随安装包分发、安装/卸载和目标机器冷启动仍待验收。
- V4.2 文档中已有的实机记录仅是继承背景；V5 跨版本、复杂建模及外部模型全流程仍需扩展验收。
