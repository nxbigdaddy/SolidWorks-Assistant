# 测试策略

## 1. 纯测试

覆盖领域序列化、工具 schema、计划校验、状态机、失败指纹、请求失效、设置加密错误、数据库迁移、
路径规范化、哈希、增量扫描、取消和日志脱敏。这些测试不得启动 SolidWorks 或访问互联网。
还覆盖需求澄清、二维预览数据、Manifest 差异、引用图、质量报告、相似度、MCP 只读门面、安全导出和
Pack and Go 临时发布。
新增 schema 3 迁移、批任务租约/恢复/幂等性、产品族矩阵、装配/工程图协议、健康与 DFM 规则、语义搜索、示教配方审批/引导回放、PDM 门控和能力实验发布门禁。

## 2. Fake 边界测试

使用 Fake Worker/适配器模拟成功、COM 异常、迟到响应、断开、快照不变化、部分读取和许可证缺失。
验证执行器不因 API 返回成功而跳过后验检查，不可用能力不会进入写调用，停止后不执行后续步骤。

## 3. UI 测试

使用 Qt offscreen 检查按钮状态、进度卡、内联错误、恢复面板、统一停止、实时上下文、四类工作区切换和中文文本。
真实 Windows Qt 截图用于字体、高 DPI 和配色人工检查；offscreen 不作为中文字形渲染证据。

## 4. 真实 SolidWorks 测试

维护简单圆柱、多特征零件、多配置零件、方程式/设计表、装配体和缺失引用夹具。每次复制到临时目录，
运行后验证原文件哈希不变。真实测试默认不在普通 CI 执行，由有 SolidWorks 的工作站触发。
基础建模矩阵使用脚本自行创建的未保存零件，至少覆盖三基准面、盲拉伸/中面/反向、拉伸和旋转的
Boss/Cut、旋转 Mark、端面重解析、开放轮廓拒绝、定义读回不符撤销和跨文档漂移；每个新特征都要保留
`CheckFeatureUse`、特征定义和 `GetErrorCode2` 证据。
版本矩阵至少覆盖旋转、产品族配置、持久引用配合、干涉、Pack and Go 含子装配/工程图/Toolbox、
三视图/剖视/BOM/气泡、PMI/DimXpert、STEP/STL/IGES 和工程图 PDF/DXF/DWG。每项保留 SolidWorks 修订号、Interop 版本、输入/输出哈希和重开 manifest。

## 5. 发布门禁

`ruff`、`compileall`、纯测试、UI 测试、PyInstaller 构建、EXE 冷启动和 ZIP 内容审计全部通过。发布包
扫描禁止扩展名与敏感文件名，帮助文档验证 UTF-8/CHM 可读性。

仓库日常验收不等同于发布验收：未执行 PyInstaller、真实 SolidWorks 或 EXE 冷启动时，只能报告
源码门禁通过，不能声称发布包完成。
