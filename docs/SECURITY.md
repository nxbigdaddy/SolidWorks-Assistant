# 安全与隐私

## 1. 凭据

API Key 使用当前 Windows 用户 DPAPI 加密。解密失败时配置进入“需要重新输入”状态，禁止携带空
Key 继续请求。日志只记录服务主机、模型和状态，不记录 Authorization、Key 或 DPAPI 密文。

## 2. 网络

只有用户配置模型服务并点击生成/修复时才发送需求和工具 schema。重定向默认禁止；TLS 证书按系统
信任验证；响应大小和超时有上限。文件 Manifest 只有在用户明确发起基于文件的规划时才发送。

## 3. 文件

快速扫描只读。源 CAD 文件永不作为派生写入目标；目标必须是新路径。发布前后计算源哈希，异常则
停止。临时目录必须位于允许工作区，清理前验证绝对路径。

## 4. 输入与日志

模型文本按纯文本渲染，不能注入 HTML。审计记录做字段级脱敏。诊断导出默认排除需求全文、文件
Manifest、真实路径和凭据，用户可选择是否包含路径。

## 5. 发布

构建脚本从显式白名单收集代码和文档。不得打包 `old/`、数据库、日志、历史、CAD 文件、环境变量、
测试产物或开发机配置。
