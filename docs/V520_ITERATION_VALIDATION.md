# 5.2.0 通用试验恢复迭代验收

日期：2026-09-07。源码分支：`codex/v5.2-trial-workspace`。
回退基线：`v5.1.2-baseline`（`e1bb9d4`）。本轮没有构建 EXE 或安装包。

## 本轮交付

从针对零件补指令，转向可替换的候选建模程序。实际桌面运行器在宿主配置的原生副本中执行完整候选阶段，独立检查后采用；普通失败后返回原基线，再将失败与检查结果交给同一任务 Agent 修改程序。

源模型保护不是依赖 Undo。私有 RPC 没有模型可选路径、任意代码或直接 COM 权限。写前检查目标身份/配置/更新戳，执行中再次获取文档时仍需匹配候选。停止先中断 CAD worker，再关闭 Pi，避免等待推理进程退出期间继续派发 CAD 操作。

完整设计与限制见 [通用试验工作区](AUTONOMOUS_TRIAL_WORKSPACE.md)。

## 原生 SolidWorks 验收

准备了 `scripts/live_candidate_trial_smoke.py`，本地固定测试后端，不读取配置模型密钥、不发送外部模型请求。

```powershell
.\.venv\Scripts\python.exe scripts/live_candidate_trial_smoke.py --execute --start-solidworks --budget-seconds 1800
```

固定流程：初始化新测试零件；错误宽度候选应体积验收失败并恢复；修改宽度候选应通过；复制非空基线后切孔；独立复测体积和三轴极值。

首次执行前本机没有 SolidWorks 进程，显式启动新实例，没有原用户模型参与。后续复测附着同一实例，保护并恢复此前测试留下的活动文档。脚本不关闭测试文档、不删除候选文件，保留现场；若已有用户文档，仅检查其身份和更新戳，不读取几何作为任务输入。

已保留的失败证据：

1. `artifacts/candidate-trial-smoke/1788750991313807700-881c37aa/result.json`：595.25 秒；前两轮 `restored, committed` 成功，第三轮因 SolidWorks 返回大写 `.SLDPRT` 与宿主小写扩展名字符串不一致，被所有权检查拒绝。修复为记录经过验证的真实原生路径，未放宽 COM 文档身份检查。
2. `artifacts/candidate-trial-smoke/1788751983107303300-9f574a87/result.json`：122.05 秒；早绑定 COM 包装拒绝显式 VARIANT 输出参数。改为基于本机 SolidWorks 2025 类型库的固定白名单 `InvokeTypes` 单次调用；不得以异常后重试兼容另一形式。该次旧脚本将“切回失败”记作 original_unchanged=false，并不构成原模型被改变的证据；报告现已区分改变、未改变和无法验证。

以上失败不被计为实机通过。

## 不能据此宣称的结论

- 固定后端/假队列测试不等于真实 Pi 对未知零件的自主建模验收；本轮不发送真实 CAD 或日志到外部模型。
- 首期仍使用已有 CAD 工具，没有开放通用代码执行或全部 SolidWorks API；扫掠、放样等缺口仍需后续能力层。
- 支持新建单配置、无外部引用、可完整读取二维线弧草图的零件，不支持装配体/工程图分支。
- 跨副本端面/草图实体引用不复用；旧任务和停止留下的未完成候选需保留现场、新建任务。
- 副本保真基于明确读回证据，不是任意 B-rep 形式证明。不保证与其他外部 COM 自动化并发写入时的事务隔离；测试/运行应避免同时由其他工具建模。
- 副本文件保存的是试验开始状态；采用当前内存结果不表示最终成品已保存。原件与所有候选暂不自动清理。
- 未执行 EXE、安装器、迁移安装或卸载验收。本轮是源码迭代，不作为安装包发布报告。
