## 通用修复

### 坐标和几何结果

- 保留现有公共平面坐标约定；`_sketch_point` 只负责公共毫米坐标到模型米坐标。
- 直线、中心线、圆和矩形经当前 `ISketch.ModelToSketchTransform` 再转换到实际草图坐标，
  复用多边形已验证的显式 MathPoint 调用路径，不假设所有草图与前视平面方向相同。
- 检查变换为刚性米制坐标、正反变换一致且点位于二维草图内；写入前核验草图绑定。
- 写入前设置并验证 AddToDB/DisplayWhenAdded，避免自动吸附；恢复这些设置后再次核验。
- 独立读取新增实体的实际端点、圆心/半径、构造线状态，并检查旧实体没有被改变。
  返回的实体身份必须与实际新增实体相符，返回成功但几何不符也视为失败。
- 公共矩形相对实际草图旋转时，按四条已转换边线建立；没有因失败而盲目重放的备用调用。
- `SketchCreationError` 将有界请求点、实际 API 点、真实几何与验证错误送回 worker。
  未确认状态不返回成功、不盲目 Undo；已有隔离候选恢复仍由宿主独立核验。
- 中心线旋转签名使用实际草图局部端点；不再拿模型坐标作为不可读端点的替代值。

官方依据：[CreateLine](https://help.solidworks.com/2025/english/api/sldworksapi/SOLIDWORKS.Interop.sldworks~SOLIDWORKS.Interop.sldworks.ISketchManager~CreateLine.html)
描述在活动二维/三维草图创建线段及 AddToDB 避免推断；
[坐标变换示例](https://help.solidworks.com/2026/english/api/sldworksapi/Transform_Coordinates_from_Sketch_to_Model_Space_Example_VB.htm)
说明草图坐标与模型坐标的区别。具体本次根因来自本机指令、代码和实际几何三者的对应证据，
不是仅根据接口函数名推断。

### 失败反馈

`failure_evidence.py` 提取失败前/后的几何，只保留有限数值和明确白名单字段。
每份最多 8 个实体，超出时标明截断；剔除原生持久引用、本地路径及凭据。
读回完整与摘要截断分别标示，不把摘要称为完整几何。

反馈同时进入持续决策上下文、`diagnostics.recent` 和 Pi 原生阶段回执；原生回执只带本次阶段
新增失败，成功后的后续阶段不会错误复用旧失败。候选 finish_receipt 也保留到上下文，
即使回执体积过大裁剪试验明细，仍保留结束状态和关键失败证据。

这些数据明确标注为历史失败现场，不写回 expected_observation、当前模型或文档绑定，
不授予 Agent 新的写入、回滚、文件或 COM 权限。

### Pi 整理上下文与状态反馈

上下文压缩不再使用普通 90 秒无响应判断。每轮压缩有一个固定最多 300 秒窗口，
同时受原有整轮/决策硬期限约束；重复事件或心跳不延长期限。
压缩结束后恢复普通响应计时，仍须收到稳定完成事件才读取最终回复。
压缩超时明确暂停，不当作引擎故障而自动切换或重放 CAD。界面公开提示正在整理上下文。
原有停止、阶段超时和白名单保持有效；review 后的候选恢复提示明确“自动推进已暂停”。
