# 产品需求

## 1. 目标

应用面向需要在 Windows 上使用 SolidWorks 的设计人员，提供三条独立但可组合的
能力：自然语言生成受限建模计划；逐步执行、检查与恢复；本地 CAD 文件索引、
参数读取和安全派生。

系统不是无人监管的宏执行器，也不是 PDM。模型只能建议工具计划，本地验证器和
执行状态机拥有最终控制权。

## 2. 用户任务

- 用中文描述简单零件，先查看计划，再单步或连续执行。
- 在每个动作后看到工具、参数、耗时、模型变化和验证结论。
- 失败时选择重试、改参数、人工完成后验证、模型修复或跳过。
- 扫描本地 `.SLDPRT`、`.SLDASM`、`.SLDDRW`，不启动 SolidWorks 即可建立索引。
- 需要时启动深度读取，保存配置、属性、尺寸、特征、材料、几何摘要和引用关系。
- 用文件哈希和规范化参数哈希判断内容或参数是否变化。
- 复制源模型，或在副本上修改参数；源文件不得被修改。
- 使用官方 Pack and Go 复制装配体引用，并把零件/装配体/工程图安全导出为受支持的交换格式。
- 对比参数快照、检查引用与特征错误，并按已读取结构查找相似模型。
- 查询历史任务、审计日志、参数快照和失败原因。

## 3. 功能范围

### 3.1 智能规划

支持兼容 OpenAI Chat Completions 的模型服务和离线规则规划器。界面展示可审计的
阶段信息、耗时和结构化结果，不展示或依赖模型内部思维链。模型响应必须是 JSON，
工具名称与参数必须经过本地白名单验证。
关键尺寸缺失时先返回可回答的澄清问题，不调用模型也不猜测尺寸。

### 3.2 交互执行

执行器一次只提交一个工具。每步记录执行前后快照；API 返回成功但后验条件不成立
仍视为失败。连续执行只是自动调用同一单步接口，不存在另一套绕过验证的路径。

### 3.3 本地模型库

快速扫描与深度读取分离。快速扫描只访问文件系统；深度读取通过独立 COM 工作进程
串行访问 SolidWorks。扫描和读取均支持进度、合作式停止、失败继续和增量处理。

### 3.4 派生与重绘

第一优先级是原样复制和参数派生；简单且能力报告完全支持的零件才允许重绘。
装配体复制使用 Pack and Go。写操作在临时工作区中进行，验证后发布。

## 4. 非功能需求

- UI 操作后 100 ms 内必须出现反馈；长任务每秒至少更新耗时。
- 任何失败不得丢失已完成步骤、输入需求或上一次成功参数快照。
- 日志和数据库固定 UTF-8；API Key、Authorization 头和 DPAPI 密文不得进入日志。
- 1000 个文件的索引列表必须分页；未变化文件不重复深度读取。
- 不强杀用户正在使用的 SolidWorks 进程。COM 工作进程可断开并重建。
- 发布包不得包含真实 CAD 文件、本机数据库、日志、历史或凭据。

## 5. 完成定义

纯 Python 测试、UI 测试、进程边界测试和真实 SolidWorks 回归同时通过；新 Windows
用户可安装、配置、生成计划、执行简单圆柱、建立文件索引并查看审计记录；失败路径
给出具体恢复动作，且源 CAD 文件哈希保持不变。
