# 交互与状态流

## 1. 生成计划

1. UI 校验非空需求并立即显示进度卡；本地预检发现关键尺寸缺失时列出问题并停止规划。
2. 控制器记录 `planning_started`，生成请求号。
3. 规划器依次报告准备、请求、接收、解析、校验。
4. 本地校验成功后载入执行器；失败时保留需求并显示可操作原因。
5. 用户停止后请求号失效，迟到响应不得改变界面。
6. 计划通过后本地绘制受支持草图的二维预览和特征摘要，供执行前核对。

## 2. 执行计划

1. 执行器读取当前步骤并校验参数。
2. COM 工作进程采集执行前快照。
3. 执行单个动作并采集执行后快照。
4. 后验验证器判断真实状态变化。
5. 成功则提交步骤并进入下一步；失败则进入暂停。

连续执行模式仍在每一步返回主状态机，不能把整批命令一次性提交给 SolidWorks。

## 3. 失败恢复

暂停状态提供五条路径：环境调整后重试一次；编辑参数；人工操作后只验证；把失败上下文
交给模型替换后缀；确认依赖风险后跳过。任何恢复都保留成功前缀。

## 4. 文件库扫描

快速扫描发现文件、计算有界快速指纹、增量写入数据库并标记缺失文件。取消时保留已完成
结果，但不执行“标记缺失”收尾，避免未扫描文件被误判。
扫描、深度读取和派生共享一个互斥任务槽；重复启动会被拒绝，不会清除当前任务的取消标志。目录遍历
发生权限错误时任务标记为不完整，并跳过缺失状态收尾。

## 5. 深度读取

深度读取逐个把文件路径发送给 COM 工作进程。单文件失败继续；COM 断开则终止批次并提示
重连。Manifest 规范化后计算 SHA-256，相同参数不创建重复快照。

## 6. 安全派生

计划时记录源文件 SHA-256；执行前再次核对。目标必须不存在且位于允许目录。修改只发生在
临时副本，重建和重新打开验证成功后才提交。失败现场可保留用于诊断，源文件不变。

## 7. 装配体 Pack and Go

从模型库选择装配体并指定一个尚不存在的输出目录。服务先记录源装配体完整 SHA-256，在同级唯一临时
目录中调用 SolidWorks 官方 Pack and Go，检查所有输出文件非空、至少包含一个装配体且未越出临时目录，
再次核对源文件后才发布目标目录。失败、取消或 API 返回非零状态时删除临时输出，不覆盖已有目录。

## 8. 格式导出与库分析

导出与派生共享互斥后台任务槽，写临时文件并核对源 SHA-256 后发布。库分析也在后台运行，可用“停止”
取消大规模依赖遍历或相似度计算；差异和质量结果写入详情区，不修改模型库快照或 CAD 文件。
