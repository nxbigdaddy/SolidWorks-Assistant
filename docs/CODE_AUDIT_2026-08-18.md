## 已修复问题

1. 非 XY 草图坐标原来没有按 `origin + x*u + y*v` 转换，导致上视、右视和派生端面上的几何位置错误；现已修正并覆盖四类坐标系测试。
2. 草图和特征后验原来主要检查数量变化，错误尺寸可能被当成成功；现增加结构化几何证据，拉伸和旋转还会从 `IExtrudeFeatureData2` / `IRevolveFeatureData2` 重新读取实际参数。
3. 拉伸或旋转创建后若重建、定义读取或参数核对失败，原来可能残留半成功特征；现会撤销最后特征并再次重建，回滚失败时明确要求人工检查。
4. 排队任务请求暂停后可能停留在不可恢复状态；现排队任务直接进入 `paused`，运行中任务仍在原子操作边界暂停。
5. 执行计划原来没有统一使用 Add-in 实时上下文门禁；现按工具访问范围检查命令占用、上下文新鲜度、活动文档标题和只读状态。
6. 自动修复请求和“重试/替换/跳过/人工确认”可能并发覆盖；现所有人工恢复操作都会使尚未返回的模型修复请求失效，UI 在修复期间禁用全部恢复按钮。
7. 能力矩阵原来可能读取旧进程留下的快照，并把 Interop 反射表述成运行成功；现必须匹配当前 Add-in 进程、SolidWorks 修订号和连接时刻，并明确标记为声明级证据。
8. Event Bridge 普通事件拥塞时原来会静默丢弃，且可能影响命令边界；现命令/桥接/销毁事件可越过普通积压上限并保持 FIFO，普通丢弃会累计计数和诊断。
9. “日志保留天数”原来只保存设置、不执行；现启动时仅清理过期的 `session-*.jsonl`，保留无关文件，并审计删除结果或错误。
10. 安装器提权重启原来没有转发全部开关，自定义目录安装后卸载器又会拒绝该目录；现完整转发参数，并通过 EXE 与版本标记验证自定义安装根目录。
